# 配对MI失败分析与改进依据

所有诊断和匹配控制已经完成，当前无活跃训练。最终表见[RESULTS.md](RESULTS.md)，协议见[PROTOCOL.md](PROTOCOL.md)。本文件保留影响当前方案选择的证据，历史过程由Git归档。

## 原决策头的问题

稀疏分类控制每步仅2条分类监督，第400步全部1000条源验证都选择A，正常/被试内信号打乱均48.8%，交换选项51.2%。字母对应语义随选项随机化变化，因此这里48.8%不是固定左右手标签下的多数类率。

增加覆盖为每步32条分类监督后，随机选项控制第200步全部选B，正常/打乱均51.2%。固定A=左手/B=右手后，第100步独立分类审计为50.2%（990次A、10次B），打乱同为50.2%；第200步全部右手，50%。因此分类覆盖和选项稳定性均不足以修复决策塌缩，停止继续四卡优化。

控制权重/日志分别保存在 `artifacts/jev_paired_qa/control_sparse_labels/`、`control_random_options/`、`control_fixed_mapping/`。不同选项条件下准确率不能直接相减后解释为同条件改进；最终比较统一使用同一固定映射、同一第100步checkpoint。

## 编码器并非完全没有可读信息

相同OpenBMI划分、相同三通道配对输入，StandardScaler+Ridge训练内被试选参后，源验证结果：

| 特征 | 左右手准确率 |
|---|---:|
| 两段功率及差值 | 56.2% |
| REVE两段池化 | 58.5% |
| REVE仅任务段池化 | 59.6% |
| 经过投影器入口LayerNorm后池化 | 59.0% |
| 仅token均值/标准差 | 52.4% |

LayerNorm审计不支持其删除了主要可读分类信息；两段/任务段的小差距也不足以声称参考段有害。频带属性标签由功率阈值构造，对应功率读出只是管线正控制，不能当独立神经生理证据。

REVE分类标签预算400/800/3200/8800对应52.8%/52.9%/55.9%/58.5%。这解释了增加覆盖的动机，但实际JEV控制未获改善。证据在 `diagnostics/`、`diagnostics/normalization/`、`diagnostics/label_budget/`。

## 决策位置探针与联合修复

同一冻结第100步模型提取9800条源train/val的最后决策状态与REVE特征。语言state单独读出在3200/8800标签下仅52.2%/52.3%，REVE为55.9%/58.5%。这些结果说明当前线性读出下语言路径弱于REVE；不证明所有EEG信息已被抹除，不足以判定某一层的因果责任。

因此保留语言路径并增加REVE旁路，冻结所有主干参数，仅拟合联合读出。联合源验证55.0%/58.7%，端到端4000条预测精确复现离线；外部2b为63.20%/63.84%，打乱后50.53%/51.13%，恢复了信号相关决策。但REVE同预算为63.59%/64.96%，未发现语言分支额外收益。

特征、划分、float64读出、导出头与hash在 `diagnostics/fixed_step100_readout/`；真实模型推理与原头控制在 `readout_evaluation/`。首次float32解算产生数值警告后改为float64复核，最终准确率一致；原数值控制产物保留，不使用不稳定输出作结论。

## 下一阶段的判据

本轮修复已验证，但通用EEG语言理解与情绪分类改善仍未被证明。继续语言路线应要求超过同标签预算REVE，并通过问题条件变化、信号打乱及被试隔离评估；不能因为loss下降或属性题高分就继续扩大训练。2b已被查看且列入REVE预训练，不再将其包装为全链路未见数据的盲测。当前不按本轮2b结果调整超参数或追加训练。
