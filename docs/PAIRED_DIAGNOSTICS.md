# 配对 MI 表示与训练覆盖诊断

本诊断属于当前配对MI方案的匹配对照，不改变正在运行的模型或数据。CPU脚本：`scripts/diagnose_paired_representation.py`，产物：`artifacts/jev_paired_qa/diagnostics/`。

## 固定诊断设计

同一OpenBMI 8,800训练trial / 1,000源验证trial、相同C3/Cz/C4、相同2秒baseline/task与相同REVE缓存。原44名训练被试中seed42随机取9名做内部验证，另外35名拟合StandardScaler+Ridge多输出one-hot读出。alpha候选固定10/1000/100000，逐问题按内部验证平衡准确率选择，再合并44名训练被试重拟合；外层5名被试仅评价一次。所有预处理随Pipeline仅在相应训练分区拟合。不使用2b。

比较：两个频段的两段log功率及其差值；REVE每段每通道对三个时间patch取均值后拼接（3072维）；仅任务段相同池化（1536维）。池化线性读出的失败不能证明完整或非线性表示没有信息。源验证集此前已多次查看，不能称为盲测。

## 结果

| 读出 | 左右手分类：全部1000题 | MI属性：与JEV完全相同的固定panel |
|---|---:|---:|
| 频带功率线性读出 | 56.20% | 65.97% |
| 两段REVE池化线性读出 | 58.50% | 48.96% |
| 仅任务段REVE池化线性读出 | 59.60% | 44.44% |
| 当前JEV，第200步 | 48.80% | 34.03% |

分类为普通/平衡准确率（类别均衡），属性为六题平衡准确率平均。频带属性标签本身由功率阈值构造，功率读出的高分只是管线正对照，不是独立神经生理证据。

REVE包含当前线性探针可读取的分类与属性信息，不能把JEV失败全部归因于encoder。两个探针的58.5/59.6差距不足以声称基线有害或无用。探针使用全部训练标签，而JEV第200步只见400条分类监督，二者存在训练量差异，不能据此单独定位为语言架构问题。

## 首要改进假设

原每步56题中，仅2题是最终左右手分类，另外54题为属性。即使分类loss权重为25%，也不会增加分类监督覆盖；训练400步仅800条次，占8,800分类题的9.1%。两个样本承载25%梯度也可能增加噪声。

优先仅调整采样覆盖：每步每个左右手类别16条，总32分类题；54条属性题不变，全局batch86；保持分类/MI属性/情绪属性loss质量25%/25%/50%，保持REVE冻结、MLP、LoRA、学习率与初始化不变。计划600步，每275步覆盖全部8,800分类题一次，总19,200分类条次；每100步验证。以同一源验证panel与初始/旧运行比较，并保留旧运行作为匹配控制。不在此阶段同时改encoder、输入特征或添加手工分类分支。

旧运行第400步MI分类仍为48.8%、MI属性34.375%、情绪属性39.93%，保存完成后已停止，全部进程退出后才修改代码。对照保留在 `artifacts/jev_paired_qa/control_sparse_labels/`，新方案重新从相同初始化启动。此时仍是待验证假设，不能声称改进有效。
