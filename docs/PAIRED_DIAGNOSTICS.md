# 配对 MI 表示与训练覆盖诊断

本诊断属于当前配对MI方案的匹配对照，不改变正在运行的模型或数据。CPU脚本：`scripts/diagnose_paired_representation.py`，产物：`artifacts/jev_paired_qa/diagnostics/`。

## 固定诊断设计

同一OpenBMI 8,800训练trial / 1,000源验证trial、相同C3/Cz/C4、相同2秒baseline/task与相同REVE缓存。原44名训练被试中seed42随机取9名做内部验证，另外35名拟合StandardScaler+Ridge多输出one-hot读出。alpha候选固定10/1000/100000，逐问题按内部验证平衡准确率选择，再合并44名训练被试重拟合；外层5名被试仅评价一次。所有预处理随Pipeline仅在相应训练分区拟合。不使用2b。

比较：两个频段的两段log功率及其差值；REVE每段每通道对三个时间patch取均值后拼接（3072维）；仅任务段相同池化（1536维）。池化线性读出的失败不能证明完整或非线性表示没有信息。源验证集此前已多次查看，不能称为盲测。

## 结果

| 读出 | 左右手分类：全部1000题 | MI属性：与JEV完全相同的固定panel |
|---|---:|---:|
| 频带功率线性读出 | 56.20% | 65.97% |
| 两段REVE池化线性读出 | 58.50% | 48.96% |
| 仅任务段REVE池化线性读出 | 59.60% | 44.44% |
| 当前JEV，第200步 | 48.80% | 34.03% |

分类为普通/平衡准确率（类别均衡），属性为六题平衡准确率平均。频带属性标签本身由功率阈值构造，功率读出的高分只是管线正对照，不是独立神经生理证据。

REVE包含当前线性探针可读取的分类与属性信息，不能把JEV失败全部归因于encoder。两个探针的58.5/59.6差距不足以声称基线有害或无用。探针使用全部训练标签，而JEV第200步只见400条分类监督，二者存在训练量差异，不能据此单独定位为语言架构问题。

## 首要改进假设

原每步56题中，仅2题是最终左右手分类，另外54题为属性。即使分类loss权重为25%，也不会增加分类监督覆盖；训练400步仅800条次，占8,800分类题的9.1%。两个样本承载25%梯度也可能增加噪声。

优先仅调整采样覆盖：每步每个左右手类别16条，总32分类题；54条属性题不变，全局batch86；保持分类/MI属性/情绪属性loss质量25%/25%/50%，保持REVE冻结、MLP、LoRA、学习率与初始化不变。计划600步，每275步覆盖全部8,800分类题一次，总19,200分类条次；每100步验证。以同一源验证panel与初始/旧运行比较，并保留旧运行作为匹配控制。不在此阶段同时改encoder、输入特征或添加手工分类分支。

旧运行第400步MI分类仍为48.8%、MI属性34.375%、情绪属性39.93%，保存完成后已停止，全部进程退出后才修改代码。对照保留在 `artifacts/jev_paired_qa/control_sparse_labels/`，新方案重新从相同初始化启动。此时仍是待验证假设，不能声称改进有效。

## 投影器入口 LayerNorm 审计

使用同一脚本的 `--normalization-audit` 模式，将初始化投影器的真实LayerNorm参数（gamma/beta、eps=1e-5）应用于每个REVE token，再做同样的通道内时间池化与内部被试验证选参。NumPy实现已与PyTorch layer_norm逐元素核对。没有修改活跃模型或重新编码数据。

| 表示 | 全部1000题左右手准确率 | 全部6000属性题：六题平均平衡准确率 |
|---|---:|---:|
| 原始REVE两段池化 | 58.50% | 52.18% |
| 实际LayerNorm后两段池化 | 59.00% | 52.28% |
| 仅token均值/标准差 | 52.40% | 37.65% |

这些小幅差异不能解释为LayerNorm带来显著提升，但不支持“LayerNorm移除了主要分类/属性信息”的假设。保留当前LayerNorm，不因直觉同时修改架构。这里属性列使用完整验证题，不能与上表的固定panel数值直接相减。

产物 `artifacts/jev_paired_qa/diagnostics/normalization/`，包括协议、逐题/逐被试成绩、预测数组和完成哈希。探针遵循训练内Pipeline拟合，源验证已被多次查看，不是新的盲测。

## 分类标签预算对照

`--label-budget-audit`精确复用了JEV seed42左右手组的初始队列前缀，每类取预算的一半。不同预算共用训练内被试划分；标准化和Ridge选参只使用各自预算内的数据，然后在同一1,000题源验证集上评价。使用两段REVE通道池化特征，无LayerNorm。

| 不同分类训练trial数 | 源验证准确率 |
|---:|---:|
| 400 | 52.8% |
| 800 | 52.9% |
| 3,200 | 55.9% |
| 8,800 | 58.5% |

这支持增加覆盖的动机，不证明JEV会具有相同学习曲线；不同预算选出的正则强度也可能不同。产物在 `artifacts/jev_paired_qa/diagnostics/label_budget/`，保存选参曲线、样本源ID、逐被试结果和预测。

## 最终分类专用控制评估

`scripts/evaluate_paired_classification.py`针对固定checkpoint评估全部1,000条分类题：匹配信号、交换左右手选项顺序、被试内打乱完整baseline/task信号对。记录逐被试普通/平衡准确率、混淆矩阵、选项交换后的语义一致率与匹配减打乱差值。打乱保持被试身份及每条信号的出现次数，避免仅靠被试分布差异解释结果。

该评估器尚未对新训练后的checkpoint运行。需在训练完成后或使用不可变checkpoint副本运行，不改动活跃作业。入口会记录权重/数据哈希，并拒绝评估期间权重变化的结果。最终结论不能只依赖属性提升，也不能仅以选项交换一致作为信号利用证据。

## 第400步旧模型的反事实实测

已用不可变 `control_sparse_labels/last.pt` 完成全部1,000个验证trial的真实JEV推理。正常输入准确复现原验证48.8%，确认专用评估器与训练验证一致。

| 条件 | 左右手准确率 | 选择A/B次数 |
|---|---:|---:|
| 正常EEG和原选项顺序 | 48.8% | 1000 / 0 |
| 相同EEG，交换左右手选项 | 51.2% | 1000 / 0 |
| 同被试内打乱完整信号对，保留原选项 | 48.8% | 1000 / 0 |

交换选项后的语义一致率0%；正常减打乱准确率0个百分点。正常情况下A/B logit差仍随输入变化（均值0.1561、标准差0.0533），因此不能声称模型内部完全忽略EEG；但其最终分类决策全部固定在A，不能支持有用的信号分类能力。48.8%恰好等于此固定选项排列中真实答案为A的比例。

这将问题具体定位为最终决策的固定字母塌缩，不能据此单独证明选项随机化、encoder或某层是因果根源。覆盖改进仍在运行，下一次检查需要同时评估准确率和字母分布；如果继续固定字母，再考虑稳定分类标签映射或更直接的接口监督，不把训练loss下降当作恢复。

证据：`artifacts/jev_paired_qa/control_sparse_labels/classification_audit/` 的results.json、三份逐trial logits/predictions npz及complete.json。评估在GPU3约83GiB空闲时启动，限制独立分配为设备显存的48%，与原训练并行；峰值总占用约113GiB，评估完成后显存释放，当前训练持续运行。
