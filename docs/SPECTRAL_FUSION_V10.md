# v10：空间对齐的REVE与频带功率融合

动机：v3/v4简单频谱在源域情绪识别有信息，而v8末层微调无源验证收益。检验显式频谱能否补足冻结REVE，不预设提升。

在与v6相同八个空间锚点上，将每通道5个频带log power按同一坐标高斯权重汇聚，得到8×5；REVE为8×512。频谱各特征仅使用源训练行拟合均值/方差，验证行不参与。冻结encoder。

四卡四组：仅REVE普通头（512维/锚点）、仅频谱普通头（5维）、拼接融合普通头（517维）、拼接融合文本sigmoid（517维）。保持源被试划分、1500step、batch96、lr1e-4、seed42及验证选模规则不变。各组参数量并不相等，不能归因于单一语义因素。

频带1–4/4–8/8–13/13–20/20–30Hz。情绪复用v4的60个有效电极log power减log窗口方差（未clip）；MI使用v1逐通道zscore/clip15后的功率。该细小预处理差异需保留说明，不能声称两路径完全相同。没有目标标准化或适配。

只跑源验证，本轮不追加外部筛选。输出`artifacts/spectral_fusion_v10_*`；标准化参数及训练行数量在每组`spectral_audit.json`。单测保证验证值不影响标准化、常数特征处理有限。
