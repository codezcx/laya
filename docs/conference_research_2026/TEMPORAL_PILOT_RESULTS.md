# 纵向先导结果：目前不能确认个人优势的稳定性

2026-10-25。事前协议与代码在 Git `829832d` 锁定，随后执行一次。结果不支持宣布 EEG 模型不可信，也没有证明个人优势稳定或不稳定。

## 执行范围

原始 BNCI2014-004、B03–B09、每人 03T/04E/05E 三次反馈会话，共 3,360 个试次。每会话前 80 训练、后 80 查询；两条管线为 A=CSP+收缩 LDA、B=通道 log-power+收缩 LDA。没有读取 B01/B02，没有训练/调用基模，没有改变现有训练实现。双极 EEG 保持原导联定义。

这是跨会话先导；MAT 中没有记录日期字段，因此没有独立核验每对反馈会话相隔的日数。正式“跨日”研究须验收日期元数据。反馈状态、稳定伪迹和有限查询噪声仍可能影响结果。

## 本会话匹配重拟合的相对优势

下表为 A−B 的平衡准确率差，单位百分点；每格的两条管线使用相同 80 个训练和 80 个查询试次。

| 用户 | 03T | 04E | 05E |
|---|---:|---:|---:|
| B03 | 5.00 | 3.75 | 3.75 |
| B04 | 1.25 | −3.75 | 0.00 |
| B05 | 1.25 | 8.75 | 7.50 |
| B06 | 0.00 | 1.25 | −2.50 |
| B07 | 2.50 | 5.00 | 8.75 |
| B08 | 1.25 | 1.25 | 0.00 |
| B09 | 2.50 | 1.25 | 2.50 |

首次会话差值与后两次平均差值的 Pearson r=0.345；按人配对 bootstrap 的 95% 百分位区间约 [−0.334, 0.937]。20,000 次中 5 次退化样本无法计算相关，区间用其余样本。7! 对应关系置换的双侧 p=0.483。两两相关分别为 0.211、0.431、0.763。

这些描述量尚未分离有限测试误差、会话变化、稳定个人成分，也未校正共同的任务难度。小样本 bootstrap 覆盖没有保证，置换解释依赖人员对应在零假设下的可交换性。不能从宽区间或 p>0.05 得出“没有稳定性”，也不能把后两次的较高相关挑出来作为主要结论。

## 早期选择的比较发生退化

首次会话六人 A 优于 B、一人平局；按照事前平局选 A 的规则，七人的个人策略都选 A。其他六人首次会话均值决定的全局策略也都选 A。因此两策略在后续会话使用相同历史池、相同模型和相同预测，差值严格为零。

| 后续两会话策略 | 人均平衡准确率 |
|---|---:|
| 早期个人选择 | 81.607% |
| 其他人决定的全局选择 | 81.607% |
| 固定 A、使用全部允许历史标签适应 | 81.607% |
| 固定 B、同样适应 | 79.911% |
| 两条管线均匀概率集成 | 81.607% |
| 按未来查询结果事后选优（不可部署） | 82.143% |

软件返回收益区间 [0,0]，只反映七个观测策略差值全为零；**不是对未来人群“个体化无收益”的精确置信结论**。不能将本次结果作为宽泛否定个体化的证据。这个两模型集合及早期选择规则没有产生不同个人选择；本轮按协议停止，不改预算或增加模型追求赢家分化。

## 验证与可复现性

所有输入文件、锁定脚本、协议和运行产物哈希匹配。84 组保存概率数组均有限、非负且归一；从标签与 argmax 预测独立重算 42 个本会话 BA，与报告逐项相同；全部 14 个历史适应决策行、集成及事后 oracle 分数也独立重算。两条管线在已知方差差异的合成信号上准确识别类别，并通过训练/查询联合幅度缩放不变性检查。CSP 的广义特征方程逐次验证残差。训练/查询按固定不相交前后缀建立，历史池只使用过去会话和当前前缀。

原始预测及计划在 `artifacts/benchmark/temporal_preference_pilot/`；小型[结构化结果](sources/eeg_trust/temporal_pilot_result.json)与[核验记录](sources/eeg_trust/temporal_pilot_verification.json)随 Git 保存。[事前协议](TEMPORAL_PILOT.md)保留原文，未按结果修改。单次运行含 70 次轻量 LDA 拟合，使用 CPU，未使用共享 GPU。

## 对问题定义的影响

保留“个人相对优势能否跨日重复并产生未来决策价值”的可检验问题，但不能将其前提写成“个人最佳模型必然会换”或“基模不可信”。下一阶段需要带可核验日期、兼容基模导联定义的队列，按独立开发用户锁定有限模型组，并通过重复测试块/拟合结构估计测量误差。完整研究包含冻结编码器与经典管线比较，本先导没有替代这项要求。

下一队列验收已发现日期顺序问题：Yang2025 sub-1 的 ses-1 日期晚于 ses-2，见[原始元数据抓取](sources/eeg_trust/yang_session_metadata.json)。下一次拟合前须核对 BDF 文件头日期及事件偏移，不按会话编号默认时间顺序。
