# Yang2025 作者分数的探索性复核计划

2026-10-25。此前已查看作者 `result.csv` 的前半部分；本分析明确属于探索性二次分析，不称事前注册或确认性检验。原始文件来自数据作者公开 ZIP，按字节范围读取后验证 CRC；不执行作者程序。

问题仍为“个人相对解码优势能否跨日重复”。先复核现有作者分数，以判断研究可行性和测量限制；不因某一模型对结果更好而只展示该对。

## 数据和排序

只使用 Dataset 1 的 51 人×3 会话×5 模型分类准确率。两类任务各 100 次，作者报告 within-session 10-fold CV；不把 153 个会话当独立用户。Dataset 2 为不同三类任务，不合并。严格检查被试/会话完整性、取值范围和原表汇总。

通过 NEMAR v1.0.5 的信号文件头日期建立每人真实记录时间顺序。编号不是日期顺序；至少 sub-1 已在 NEMAR BDF、scans 和 Figshare 原始 BDF 头三处核对。全体日期可能仍受记录时钟影响，不将文件头当外部校准时钟的证明。必须先取得全部 153 个日期，再做完整队列分析，不能把网络访问成功子集当随机样本。

**元数据验收后的修订，发生在任何相关性/选模统计计算前：** 153 个头全部取得后，三日断言失败，首次运行在输出目录创建前停止。42 人满足三个不同日期；9 人（12、16、19、21、22、29、39、41、51）只有两个日期。主分析限定三个不同日期的 42 人；全体 51 人原分数和日期仍保留用于审计与论文汇总核对。该排除只依赖日期，不依赖模型表现；不将同日记录冒充跨日记录。图和按人 bootstrap 均使用 42 人。CSV 会话标签按作者 transform.py 对应处理后文件夹，不能直接对应同名原始文件夹。

## 固定的探索性摘要

- 报告作者表五模型均值及按原编号/文件日期排序的均值，核对论文数值是否一致。公开表与论文的版本差异单独报告。
- 重点对比 EEGNet−deepConvNet：均为端到端监督网络、作者说明使用共同训练程序。所有其余九对同时报告，避免只选关联最高的对比。
- 每人最早会话的模型差值，与后两次会话平均差值作 Pearson/Spearman 描述性相关。按人配对 bootstrap 20,000 次、seed=20261025 给出 95% 百分位区间；不做显著性筛选，十对区间不作同时覆盖或首创证据。
- 报告极端值、天花板效应、散点图和 leave-one-person-out 相关范围。标准工具检查只辅助诊断；不按正态性 p 值切换到更有利的主统计量。
- 在作者分数矩阵上演示“首日选最高分模型”与“其他人的首日均值选全局模型”，确定性平局按表列顺序。评价两者选中模型的后两日作者分数，并与每个未来会话事后 oracle 比较。这只是回顾式分数选择演示，不是新训练、在线部署或完整问题中的 V(m)：作者晚期模型没有按我们同预算历史适应规则重拟合，试次 CV 也不是时间前缀预测。

## 已知不能支持的结论

没有逐试次预测、重复初始化和精确折划分日志，不能分离观测噪声与真实会话变化。不能将作者汇总分数与本地经典先导直接合并，也不能由此断言冻结 EEG 基模的表现。论文的跨日单模型准确率分析已存在，不能作为我们首次提出的内容；本候选只保留“相对优势的重复性与可利用性”的差别，仍须查重与独立验证。

论文叙述中的第二阶段“test loss”与发布代码不完全一致：源码 `_trainOE` 接收 train/val，不接收 test；必须按实际调用链审查，不能仅凭一句话指控测试标签泄漏。预处理脚本 epoch=[0,4]，MOABB 的 interval=[1.5,5.5]，事件相对提示的含义需单独验收，不靠猜测修改既有结果。

## 会话映射更正（更正统计运行前记录）

原计算错误地令处理后会话编号等于原始会话编号，相关解释已在 Git `42a6381` 撤回；旧结果归档于 `a4cf3c0`。现已使用全体 153 个处理后 MAT 的完整 200 项标签序列与原始 evt.bdf 匹配：51 人均具有唯一排列，全部为完整序列相等，无删试次匹配。25 人的两种编号不同，但处理后编号全部按记录时间递增。处理后标签尾部读取器经 sub-1 三个完整 MAT 独立验证；原始事件 ZIP CRC、MAT 标签内部 zlib 校验通过。sub-1 三次首试次波形另提供抽查支持，不称全波形复现。

更正程序必须显式传入 [映射记录](sources/eeg_trust/yang_session_mapping.json)，检查 51 个唯一排列和完整序列匹配，再按映射取得日期。三日队列仍为原先 42 人，所有十个模型对、20,000 次 bootstrap、种子、相关统计和选择规则不变；不按更正后结果调整方案。结果仍属探索性二次分析。映射已显示正确排序即处理后编号顺序，因此更正后统计并非未接触过的独立验证。

## 个人对应关系的探索性对照（本项计算前固定）

已有相关、选择结果及全部分数均已查看，本项不是独立确认或事前注册。固定现有 42 人三日队列与首日 argmax 规则；同时报告全部五模型选择，以及此前重点 EEGNet/deepConvNet 两模型选择，不按本项结果更换组合。平局按原表顺序。

对每人后两日平均分矩阵 Y 和首日选择 c，计算真实对应效用 U，以及随机交换 c 的精确期望 M（保持每种模型的选择人数不变）。主描述量 T=U−M，只衡量该分数表中个人对应关系的增量，不等于优于最强全局模型，更不是重新训练后的 V(m)。完整置换允许固定点；另给出排除自身作为选择来源时的期望对照。

报告按整个人重采样 20,000 次的百分位区间；每次重新计算选择频率和总体模型均值，而非把它们当已知常数。报告 20,000 次人员对应置换的双侧参考 p 值及两项对比的 Holm 调整，seed=20261025。其交换性假设不等于真实随机试验，不能作神经机制因果推断。报告全部模型对总 T 的贡献与逐人留一范围，防止一个稀有选择用户支配结论。不给本项阴性结果追加新组合。

同时显示原本的留一首日全局选择成绩。保持两种结论分开：拥有可预测的个人对应信息，不保证简单选择规则胜过全局强模型；输给全局模型也不证明个人信息不存在。作者汇总分数的 CV、训练信息、测量噪声、预处理及预训练模型缺失限制全部沿用。本对照是已知的匹配检验，不声称统计方法创新。
