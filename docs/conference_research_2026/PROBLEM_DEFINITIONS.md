# 当前候选：目标校准上下文受限时的 EEG 管线比较

状态：2026-10-25，定义草案；现实机制有证据，新颖性未通过。旧边界问题与证明归档于 Git fae0972。本文不提出新的模型，不把下列标准统计推导当作论文创新。

## 1. 一句话与具体场景

新用户戴上设备后，只有前 m 个已完成试次可用于无标签归一化/对齐。我们能否有证据地说：某个自适应 EEG 管线相对于固定管线，能给足够多的新用户带来收益，而不是只有平均分更高？

先固定一个 cue-based MI 任务及类别含义，例如左右手想象。标签由实验指令提供，窗口由已记录 cue 和固定偏移确定。这里没有“未知事件边界”。任务是分类规定窗口中的实验条件；不把正确预测条件自动解释为已证明读取了纯粹的运动意图。

候选必须满足三个层次：
1. 现象：管线确实使用目标试次集合的统计量——已由代码和原始论文核实。
2. 失败：减少决策前上下文，确实改变比较结论或新用户受损比例——尚未在我们的匹配实验中核实。
3. 新贡献：已有在线对齐、模型选择、风险控制框架不能直接覆盖目标——尚未核实。

## 2. 输入和信息约束

- 已冻结的源训练数据、模型权重、模型选择规则和窗口定义。
- 固定参考管线 B，仅使用源训练得到的统计量或逐试次操作。
- 自适应管线 A，只根据允许的目标上下文估计统计量；若允许梯度更新，必须另列为不同适应规则，不能在同一个结果中混合。
- 新被试 s 的有序试次，原始 event、run、session 元数据保留。
- 预先固定预算集合 M（例如 0、8、16、32、64；须满足实际可用数量）与最大预算 m_max。
- 所有预算使用完全相同的 query 集 Q_s：它位于最大校准前缀之后。这样减少 m 不会同时把测试集换成另一批更难/更容易的试次。
- 上下文 C_s,m 仅取决策前的 m 个试次；不看 query labels、不按有利类别比例挑试次、不用未来 query signals。
- 标签可供最终评价，但模型的适应模块不可见。cue 数据中的标签由实验设计给定；“少标签成本”未必是人工标注时间，还可能是新用户完成校准的时间。

预测写成 F_A(x;C_s,m)，而非省略上下文的 f_A(x)。

完整目标会话参与归一化是另一个有效的离线任务。可把它作为诊断参考，但不能作为在线可用的同预算竞争者，也不能仅因它是 transductive 就称其泄漏。

## 3. 输出与可信性承诺

对固定 query 集先报告有界、按预定类别权重计算的每用户经验错误率：

Rhat_s^A(m) = average_{(x,y) in Q_s} loss(F_A(x;C_s,m),y)。

记差值 D_s(m)=Rhat_s^A(m)−Rhat_s^B。负值是适应更好。

必须同时报告：
- 用户平均差值 E_s D_s(m)；
- 用户差值分布及实质受损比例 h_m=P_s(D_s(m)>epsilon)；
- 相同 query population 上，模型排序随 m 的变化；
- 实际校准时长、推理延迟和拒判/覆盖比例（如果有拒判）。

epsilon 是事先规定的实际差异阈值。一个示例可信性目标是：以 95% 置信度支持 h_m≤10%。数值只是设计示例，不能由看到数据后挑选。

这里 h_m 针对明确招募总体、固定会话长度和固定获取协议下的“新用户这次会话的经验差异”。若要保证每用户无限重复试次的真实风险，需进一步处理每用户有限 query 数量和时间依赖。不能把前者自动写成后者。

“平均改善”与“多数新用户不受损”不等价；“同一 x 在不同上下文下预测稳定”与“预测正确”也不等价。任意未知中心或任意生理分布漂移下，不提供无条件保证。

## 4. 基础可行性推导：9 个用户不足以支持很强的普遍承诺

假设两个完整管线及预算 m 在独立验证前已冻结；n 个新被试独立同分布，每人同样遵守固定评价协议。令 Z_s=1{D_s(m)>epsilon}。则 Z_s 是共同受损概率 h_m 的 Bernoulli 观测。

若 n 人中没有受损者，单侧置信水平 1−alpha 的精确二项上界为

h_U = 1 − alpha^(1/n)。

证明：在受损率 h 下，零次受损的概率为 (1−h)^n。解 (1−h_U)^n=alpha；对 h>h_U，观测零次受损的概率小于 alpha，因此单侧精确检验反演给出该上界。

alpha=0.05 时：
- n=9，即使零受损，上界仍约 28.3%；
- 要把上界压到 10%，零受损时至少需要 n=29。

这是标准二项推断，**不是新定理**。它说明小样本不能支持过强的可信性宣称。同一人的数百窗口不能替代数十位独立用户；LOSO 的训练集重叠、数据驱动挑选预算或挑选模型，也不能不加处理地套这个计算。多个预算一起挑选需同步推断或独立确认。

## 5. 最近工作能否直接覆盖

| 工作 | 已处理的内容 | 我们仍需检查的差别 |
|---|---|---|
| Latent Alignment，JNE 2025 | 用目标上下文对齐；分析类比例、潜层与性能 | 是否已有上下文预算下的新用户受损率/比较认证，而非仅均值分析 |
| OSPDIM，2026 预印本 | 类别不平衡的在线无源对齐、适应速度 | 上下文预算本身不是新设置；是否有我们所需的有限样本比较保证 |
| ThinkNet，2026 作者版本 | 目标隔离的架构选择；源验证到目标排序的可靠性 | 不能首次声称“验证优胜者未必适合新用户” |
| EEG CP，2026 作者版本 | 被试漂移、覆盖不足、个体化校准 | 输出是标签集合覆盖；与管线相对受损率不同，但只换风险函数可能仍是直接应用 |
| 一般 learn-then-test / risk control / safe adaptation | 选择满足风险约束的候选 | 若我们的结果只是这些方法在 EEG 上的直接实例，则不满足用户要求的问题定义 novelty |

本次尚未完成一般风险控制、上下文稳定性和安全适应理论的逐项全文比对，因此不能声称这一候选已经新颖。

## 6. 最小辨别实验的定义，不是已启动实验

1. 固定小模型/经典管线及源训练规则；保留 source-only、逐试次归一化、目标上下文对齐三个明确的信息设置。
2. 从真实有序试次建立校准前缀和共同 query 集。不同预算不改变 query IDs、类别集合、裁窗、频带或评价权重。
3. 首先用真实时间顺序。随机重排仅作为次级对照，不能冒充在线结果。
4. 区分三个干预：上下文数量、上下文类比例、随时间的分布变化。按 query labels 反向选上下文禁止作为部署策略；可作为明确标注的机制实验。
5. 看 paired 差异、受损用户比例和预算下的排名。不能仅报告“完整 batch 最好”。
6. 把全会话未来上下文单列为离线诊断；列入适应速度与类比例的现有方法对照。
7. 若拿 2a 初检，四类任务与其他二类数据集分别分析；要进行二类跨库比较，应预先统一标签与训练协议，不能把四类模型分数与二类模型直接混比。

不启动大训练。若没有现成模型，先解决观测与协议可行性，待问题通过 novelty 审查后再决定训练什么。

## 7. 放弃条件

- 上下文受限只造成预期且已有解释的统一精度下降，模型比较没有新的结构或决策难点。
- 直接被 OSPDIM 的在线适应实验、既有模型选择或标准风险控制重参数化覆盖。
- 所谓收益来自不同 query 集、用标签选上下文、把未来试次混入校准或改变其他预处理。
- 唯一理论结果是二项置信界、Hoeffding、union bound 或一个通用“不可能性”反例。
- 无法说明目标用户/中心总体，仍想声称任意跨数据集可信。

当前候选仅进入上述审查，未达到“清晰且新颖的新课题已经确定”的状态。
