# 当前候选：个体 EEG 解码优势能否跨日重复？

2026-10-25。状态：**真实场景与可观测量明确；最近直接文献的定向查重支持一个有潜在新意的实证问题。尚未测量跨日效应，不宣称已发现失效或已证明首创。** 不启动新的基模训练。此前一般可信性定义、受损率与输入接口审查保存在 Git dc646d3 / 205d8ed。

## 1. 一句话定义

**在同一运动想象任务、固定完整管线和相同校准预算下，一个人相对更适合某个解码器的优势，有多少能在另一天重复？这种可重复的差异，是否足以让早期个体化选模优于固定模型的适应？**

例如，第一天 A 比 B 高 8 点，不足以说明“这个人适合 A”：可能 A 对所有人都更好，也可能当天的有限试次或拟合随机性造成差异。需要检验的是扣除总体优势后的个人差异，以及它对未来选择是否有用。

这个候选研究个体化的依据，不先发明新的 selector。贡献若成立，是关于个人优势的可重复性及可利用范围的新实证证据；混合效应模型、配对比较和标准算法选择工具不是创新点。

## 2. 问题为什么真实存在

- 实际 BCI 使用跨多天发生。SHU 原始数据论文采集 25 人、每人五个不同日期的左右手想象会话；标签和窗口由提示程序规定，不需要假设未知事件边界。[Ma et al., 2022](https://doi.org/10.1038/s41597-022-01647-1)
- 近期研究已发现同一会话内，不同人的最佳管线不同，并以个人 oracle 的收益构造小型模型组合。这支持研究动机，但不证明这种个人差异可跨天延续。[个体排名](https://arxiv.org/html/2606.24394)、[组合研究](https://arxiv.org/pdf/2607.22778)
- 本地已确认输入处理与读出匹配会改变结论，说明“模型”必须包含预处理与适应规则。相关四组诊断是混杂控制依据，不是本候选跨日效应的证据。[输入诊断](INPUT_FACTOR_DIAGNOSIS.md)

**真实的是反复使用与个体化选择的决策需求；尚待检验的是个人优势的稳定程度。** 不把后者写成已经证实的问题规模，也不把所有 EEG 模型称为端到端或不可信。

## 3. 输入、输出和信息边界

研究单位为“人 × 日期/会话 × 完整管线 × 拟合重复”。任务先固定为 cued 左右手 MI，各数据集分别分析，禁止混合不同类别含义。

完整管线包含参考、频带、裁窗、通道映射、归一化、编码器/特征提取器、分类头和校准规则。它在日期间保持不变；各模型在同一日期使用相同训练/查询试次和信息权限。检查元数据和采集协议变化，不把更换反馈范式当成单纯时间漂移。

主要分析采用**匹配重拟合**：每个会话都按同一预定预算拟合分类器/适应模块，在之后的共同查询试次上评价。它衡量管线家族在该训练规则下的个人优势。固定旧 checkpoint 跨天直接预测是另一种部署问题，应另列，不混入此估计。

初始有限模型组应包含至少一种经典空间/协方差管线和一种冻结 EEG 编码器的线性读出，使用独立开发被试锁定配置。基模已有的预训练暴露需审计；暴露不明时不声称新用户零样本泛化，也不解释为先天神经类型。此处不承诺某个模型组合已经选定或训练完成。

## 4. 主要估计量

对预先指定的一对管线 A、B，令

Δ_i,s = BA_i,s(A) − BA_i,s(B)。

正数表示 A 对用户 i 在会话 s 更好。不能用单个模型的准确率 ICC 代替差值的重复性；前者可能只说明某些用户对所有模型都比较容易。

将差值描述为

Δ_i,s = μ_dataset,session + u_i + v_i,s + ε_i,s。

其中 μ 是总体/系统性会话差异，u 是可重复的个人相对优势，v 是会话特有偏离，ε 包括有限测试试次和模型拟合带来的测量误差。这是分析模型与假设，不是已识别的生理分解。每格只有一个估计时，v 与 ε 不能自动分开；需要按独立时间块/拟合重复获取误差信息，并评估时间依赖的影响。

主要报告连续配对差值在不同日期的可重复部分及不确定性，不以“赢家相同百分比”作为主终点。负对照是在数据集和日期内打乱跨日人员对应关系，保留各日总体模型表现；另检查难度、天花板/地板效应与稳定伪迹是否解释结果。

第二个终点直接回答决策价值：

V(m) = E[BA_later(early-personal-choice, m) − BA_later(global-choice, m)]。

个人选择只使用早期会话，全局选择只使用独立开发集合；晚期会话的查询标签不能参与任何选择。必须比较同样允许使用历史标签的固定模型适应策略、简单集成/收缩选择。不能让个人策略使用额外历史标签，却禁止基线把同一批标签用于适应。

ρ 高不自动意味着 V(m)>0；赢家不一致也不自动意味着 ρ=0。回顾性 oracle 用于显示上限和选择偏差，不作为可部署方法。

## 6. 数据与最小辨别实验

- 本地 2b 原缓存只保留 `3test` 一个会话，不能直接用于跨日结论。原始 B03T/B03E 已核对包含 3+2 个会话，计 120/120/160/160/160 个试次；仅完成结构检查，未运行新分类实验。[本地记录](sources/eeg_trust/session_feasibility.json)
- 2b 前两个无反馈会话与后续反馈会话不能当作同一协议重复；若用于先导，只比较协议相同的会话并承认人数少。已有保留的外层测试用户继续隔离。
- SHU 提供五天重复，适合分早期选择与晚期验证。原 Figshare zip 页面要求联系作者获取密码；未联系作者。MOABB 文档列出 NEMAR 的 EDF/BIDS 发布，但它是经过裁窗和清理的版本，不能假装原始连续记录或与 MATLAB 版完全相同。需在正式实验前核对实际访问、会话日期、试次数及预处理版本。[官方加载说明](https://moabb.neurotechx.com/docs/generated/moabb.datasets.Ma2022.html)
- Yang2025 的三日 51 人数据可作为独立候选；公开版本的 dataset_description 和 participants 元数据已成功访问，完整信号尚未下载，不宣称数据验收完成。[数据发布](https://nemar.org/dataset/nm000348)

最小实验先在一个数据集建立完整的人×日×管线矩阵；主对比与预算在看查询结果前固定，使用共同的时间顺序切分。通过重复拟合与时间块估计误差；用早期日期定个人选择，晚期日期只作检验。随后在第二个独立采集队列验证方向与决策价值，不能把同一记录的两个包装版本当独立数据。

## 7. 成败与下一步

- 若稳定个人成分及 V(m) 都有实质大小：研究在哪些预算/会话条件下可利用；不自动称其生理特质。
- 若稳定成分存在但 V(m) 不优于固定模型适应：个体差异存在，当前选模不值得付出额外代价。
- 若稳定成分很小且区间足够窄：这能反驳“事后个人 oracle 意味着可持续个体化收益”的推断；区间太宽则只能报告证据不足。
- 若近邻工作已经完成上述检验，或效应完全由协议、来源暴露、调参或测试噪声解释：撤回或改写贡献，不能硬造新算法。

当前下一步是锁定数据与分析协议，再做有明确停止条件的先导。问题定义与文献差别已经具体化，跨日效应与最终论文新颖性仍需后续实证；本文件不是实验完成报告。
