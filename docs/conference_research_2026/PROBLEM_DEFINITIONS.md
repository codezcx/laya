# EEG 可信性：问题定义与立项边界

状态：2026-10-25。现实问题已确认；尚无通过新颖性审查的新课题。旧边界方向存于 fae0972，有限上下文受损率候选的完整草案存于 a3b0280。当前不启动新的训练方案。

## 1. 已确认的任务，不引入未知时间边界

输入为实验提示后固定窗口中的多通道 EEG；输出为该试次要求的运动想象类别。标签来自实验指令，窗口由事件标记与固定偏移确定。研究中须分别声明跨被试、跨会话或跨数据集，不能混成一种泛化。

提示时刻、实际神经反应时刻、裁窗时刻是三个不同对象。实际神经反应不可直接观测，并不意味着当前类别标签或裁窗存在错误。若换为连续自发事件定位，需要另行验证边界的观测机制与专家分歧，不能沿用 MI 分类数据凭空添加这个前提。

## 2. “可信”需要明确比较承诺

定义完整管线 A=(预处理、编码器、适应规则、分类头、模型选择规则)，而非只定义一个网络名称。指定任务 T、目标人群/中心 D 和信息协议 π。

我们关心的可检验量为：

Δ(A,B;T,D,π) = E_s[R_s(A;π) − R_s(B;π)]。

其中 R_s 是相同 query trials 上、同一预定损失下的错误率。Δ<0 表示 A 的平均错误更低。另报告每用户差异和受损比例，避免用均值替代对个人的承诺。

π 必须记录：决策前可用多少目标试次、是否允许其标签、能否使用整场目标记录、预处理统计量来自哪里、允许何种适应和调参。离线完整会话与在线前缀是两种有效任务，不能直接混比，也不能把前者一概叫泄漏。

因此现实问题可以明确表述为：**在固定任务和可用信息条件下，源数据上选出的 EEG 管线在未见用户或中心仍有多大的相对收益，什么可观测机制会使这个收益消失或反转？**

这是已有泛化、负迁移和模型选择问题的具体化，不是“首次提出 EEG 可信性”的新问题。公开排名反转证明比较依赖条件，不能独立证明所有模型不可信。

## 3. 已排除：把受损率认证当作新问题

旧候选要求在有限无标签目标前缀 m 下，以高置信度控制新用户受损比例。现已核对 Learn then Test 的一般风险控制设置，普通版本可以直接归约。

令 W_s 包含一位用户的完整评价包（上下文、query 信号和仅供评估的标签）。固定源训练与全部适应规则，令 λ 索引预算/管线，定义

L_λ(W_s)=1{Rhat_s(A_λ)−Rhat_s(B)>ε}。

若独立校准用户 W_1,…,W_n 与部署用户独立同分布，则 h_λ=E L_λ 是 [0,1] 内的普通风险。检验 H_λ:h_λ>h_0，构造有效单侧 p 值并控制多个 λ 的族错误率，即可选择满足风险约束的候选。这是 LTT 的直接实例化；预算风险不单调也不构成新障碍。[LTT 原文 §1.1、§2](https://arxiv.org/html/2110.01052)

注意：这里的独立有标签“校准用户”，与 A 在部署时使用的无标签“目标前缀”是两种资源。不能省略前者，声称只凭目标无标签 EEG 就保证分类正确。也不能把重叠 LOSO 拟合当作一个已冻结模型的独立校准样本。

结论：不将“换风险函数 + LTT/二项置信界”列为新算法或主定理。它仍可作为以后实验的标准评价工具。一般性保证也不自动覆盖未知中心漂移。

## 4. 已排除：仅发现输入管线影响排名

2026 年预印本 Matched-Input Estimates Differ in Sign Across Architectures 已研究 EEG 基模与监督模型的输入混杂，比较三种监督架构在两套输入下的表现；作者将差异限于描述性证据，未声称校正后显著交互。[原文 §IV-B、§V-C](https://arxiv.org/html/2609.23924)

因此，模型×预处理的交叉实验本身，以及“统一输入不一定等于公平比较”，都不足以构成首次贡献。它仍是必要对照。本地 LEAF 的 bundled intervention 不能比该先行工作支持更强的因果结论。

EEG-Arena 的公开摘要又已覆盖大规模模型比较、预训练收益和通道配置鲁棒性，进一步排除了泛泛重做一个排行榜的路线。[原始摘要](https://arxiv.org/abs/2609.32743)

## 5. 下一项研究应补的证据，而非先定一个新名字

目前保留的是一个事实驱动的机制排查任务：从已观测到的本地输入差异中，区分空间参考、频带/滤波上下文、幅值归一化及目标统计量使用。必须保持窗口、IDs、标签、冻结权重与探针规则可核对；当前验证集已反复查看，仅用于发现机制，不作为独立确认。

进入新课题需要同时满足：

1. 找到具体可复现的失败机制，而非只重复一次性能下降。
2. 对照最新论文，明确已有方法为何不能解决该机制；差别须改变可识别性、可用信息或可执行决策，不能仅换指标名。
3. 提出能够被数据否定的预测和必要对照，并在独立数据/用户上检验。
4. 说明贡献是新机制、有效方法还是数据资源。用户没有要求必须有新定理；不应人为把唯一成功标准设为推导新定理。

当前尚未满足第 1–3 项，不宣称已经找到新颖选题。不会为了满足 novelty 字样，把已知的域偏移、预处理敏感性或风险控制包装成新问题。
