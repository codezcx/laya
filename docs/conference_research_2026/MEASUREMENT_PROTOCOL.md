# 相对优势重复性的可识别范围

2026-10-25。服务于当前唯一的纵向候选；下述标准重复测量原理不是新的统计方法。

## 首先定义可观察的任务

完整管线包含输入处理、表示、分类头和校准规则。每名用户的早期会话用于选择，后续会话用于评价；个人选择与固定全局选择享有同样的历史标签及当前校准预算。主决策终点仍是未来共同查询试次上的配对收益 V(m)。一次重新训练后的跨会话模型差值，和一个旧 checkpoint 原封不动跨天使用，是不同的实验。

另一主描述量是**指定时间间隔、指定校准预算下的个人相对优势重复性**。它不等于终身不变的用户特质。必须明确比较哪两个管线、何种窗口、相隔多久，而不是报告抽象的“EEG 可信度”。

## 测量误差的最低要求

对训练已完成、共同查询样本上的预测，保留每试次配对正确性差：

`d_j = 1[A 正确] − 1[B 正确]`。

平衡准确率差为各类别中 d 的均值再平均。若查询试次在类别内独立，给定这次拟合的查询误差方差可估为 `sum_c sample_variance(d_c)/n_c / K²`。这利用了两模型在同一试次上的配对，不能用两个准确率各自的标准误代替。

但该表达式依赖试次独立。连续时间块、run 或刺激序列相关会破坏它；须保留 run/时间块 ID，并报告块重采样敏感性。当仅有两三个查询块时，不能宣称已经可靠估计这种相关结构。

重复网络初始化估计的是给定训练数据下的优化随机性。对同一校准池 bootstrap，估计的是该有限池的重采样敏感性。二者都不能自动代替另一批独立校准数据的不确定性。冻结编码器和确定性线性头没有必要重复相同计算后把重复数算成额外样本。

## 什么情况下可以讨论稳定成分

写成 `D_i,s = μ_s + u_i + v_i,s + e_i,s` 后，必须声明额外假设。例如：测量误差条件均值为零、跨日误差独立，且 v 在不同日期间不相关。满足这些假设时，跨日协方差可以提供 u 方差的信息；测量误差的方差估计可以用于解释相关的衰减。

如果 v 本身具有跨日自相关，观察到的跨日协方差同时含稳定项和缓慢变化项。有限的三次测量通常不能唯一分开二者：同一协方差矩阵可以在允许的范围内拆成不同大小的常量用户项和相关会话项。**增加同一会话的训练种子不能解决这项识别问题。** 因此稳定项只是在指定统计假设下、指定观察时段内的共同成分，不称神经类型。

必须并列报告不强制上述分解的各日期对差值关系。若估计的测量误差与总差异同量级，噪声校正后的相关可能不可辨识；不能截断负方差后悄悄给出一个“稳定性分数”。此时应报告预算下证据不足，仍可评价真实的未来决策表现。

## 下一次新拟合的必要控制

1. 先完成原始—处理后记录映射与事件时间定义；使用完整校准/查询 ID，禁止以文件编号代替日期。
2. 在独立开发用户上锁定有限的经典/冻结编码器管线和校准预算，明确预训练暴露边界；不按本次作者分数中哪一对低相关来选择主对比。
3. 同一会话所有管线用共同的时间前缀和查询试次。保存逐试次概率、真实标签、时间块和拟合状态；需要的随机拟合重复与数据重采样分别记账。
4. 早期个人选择、全局选择、固定模型历史适应和简单集成拥有相同历史信息。未来查询标签不参与选择。
5. 先报告观测重复性与实际收益，再在明确的误差/会话假设下作分解。报告全模型对及失败的识别条件，不把 oracle 上限当可部署收益。

这些条件把问题变成可审查的实验，而不是预设个人优势必然不稳定。单队列、单预算或一对模型的结果不推广为所有 EEG 模型的可信性结论。
