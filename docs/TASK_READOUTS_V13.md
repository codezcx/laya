# v13：共享读出是否造成任务干扰

固定v12完整源数据池、空间锚点、冻结REVE、3000step、batch96、lr1e-4与seed42，仅改变读出结构。

四组：共享512宽普通头；两个独立256宽普通头（总参数与共享普通头相差<1%）；两个独立512宽普通头（容量对照）；两个独立256宽文本sigmoid头。每次forward同时计算情绪与MI，不接受任务ID作为输入。训练mask仍只对已标注任务反传；单测核验其他分支无梯度。

此为任务干扰诊断，不是自动任务识别。不同任务的读出参数拆分后不再共享，但信号encoder、位置汇聚算法和输入接口仍共享。尚不能保证对新任务或新类别零样本泛化。若改善，只能支持当前两任务读出设计，不将其包装成通用语言理解。

普通共享与独立256基本参数匹配；独立512用于检查单纯容量增加。文本组与普通组输出结构不同，参数量不相等。head均从头初始化，不使用目标调整。源验证按两任务macro选一个统一checkpoint；不分别按目标拼接两个最佳分支。

配置`configs/task_readouts_v13_*.json`；输出同名artifacts目录。最初仅做源验证，外部评估若追加需先冻结全部模型并完整报告所有预定组。
